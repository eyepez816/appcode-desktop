## 💾 What Gets Copied

Appcode Desktop focuses on the two folder types that matter most when something goes wrong:

**Config files.** These are the files that remember how your Appcode installation is set up. Display options, paths, preferences, saved profiles — anything that makes the app behave the way you like. Losing these means starting from scratch and reconfiguring everything by hand.

**Export files.** These are the files Appcode produces for you. Reports, exported data, saved output — the work you actually care about keeping. Losing these can mean real, unrecoverable work.

Appcode Desktop takes both, copies them into a dated folder structure, and leaves them exactly where you can find them with ordinary Windows File Explorer.

## 🗓️ How the Dated Folders Work

Every time Appcode Desktop creates a backup, it names the resulting folder with the date of the copy. That means the folders sort themselves naturally — newest at the bottom or top depending on how you sort — and you can tell at a glance which copy came from which day.

A typical backup folder looks something like this in structure:

- A folder for the date
- Inside it, a copy of your config files
- Inside it, a copy of your export files

You do not need to rename anything, and you do not need to remember a naming convention. The app does it for you, every single time, the same way.

No. It reads your config and export folders and makes copies. Your originals stay untouched.

No. Appcode Desktop is a companion utility. It protects the folders Appcode uses; it does not replace the application.

## 🛠️ If Something Looks Wrong

**The dated folder did not appear.** Check where you pointed the backup location. It is easy to send copies to a folder you forgot about. Use File Explorer's search to look for a folder named with today's date.

**The copy seems incomplete.** Confirm that Appcode was fully closed before the backup ran, so no file was locked mid-write. Then run the backup again.

**You cannot find the app after downloading.** Open File Explorer, click Downloads in the left sidebar, and sort by Date modified. The newest file at the top is almost always what you just downloaded.

**You are not sure which copy to restore.** Pick the dated folder from just before the patch. That is the whole reason the folders carry dates.

## 🔄 Keeping Things Tidy Over Time

Dated backups pile up quietly. A quick cleanup every few months keeps things manageable:

- Keep the most recent two or three dated folders.
- Keep one older copy from a known-good period, just in case.
- Delete anything you are certain you will never need.
- Empty the Recycle Bin afterward to actually reclaim the space.

This takes about two minutes and keeps your backup location easy to scan.
